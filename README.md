## Overview

Which Mod Is This From adds a tooltip line to every modded item, NPC, and buff in Terraria identifying the mod that added it, making it easy to trace unfamiliar items back to their source mod and preventing confusion in large modpack installations where hundreds of items from different mods coexist.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Which Mod Is This From** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Item Attribution** | Tooltip shows the source mod name for every modded item |
| **NPC Attribution** | Hovering any modded NPC displays its source mod identification |
| **Buff Attribution** | Modded buff and debuff tooltips identify their source mod |
| **Large Pack Friendly** | Essential for large modpacks where items from many mods overlap |
